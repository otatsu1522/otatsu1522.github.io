自転車でのユーラシア大陸横断旅を終え、現在は一時帰国しています。

今回は、この旅の全体像を「日数」「距離」「費用」などの数値データから振り返ります。

---

## 旅の概要

- **全期間**: 364日間
- **訪問国数**: 40か国（※コソボ含む / トランジット除く）
- **総移動距離**: 23,416.99 km
- **総出費**: 550,405 円

---

## 日数と移動スタイル

旅全体の期間は**364日間**（約1年間）でした。

- **全期間**: 364日
- **宿泊・停滞日数**: 102日（約2か月半）
- **実質移動日数**: 約262日（約9か月）

街での停滞や休養が102日あり、実際に自転車で移動していた期間は約9ヶ月間です。

---

## 訪問国数とルート

通過した国はコソボを含めて**全40か国**です（トランジットのみの国は除く）。

直線的な最短ルートではなく、気になる地域を経由しながら進みました。なお、ビザの制限や安全面、海を渡る都合上、一部区間は飛行機で移動しています。

---

## 走行距離

サイクルコンピューターの不調による一部計測漏れを含みますが、記録上の数値は以下の通りです。

| 項目 | 距離 |
| :--- | :--- |
| **総移動距離** | **23,416.99 km** |
| **1日平均（全364日換算）** | 64.33 km / 日 |
| **1日平均（移動日のみ換算）** | **86.73 km / 日** |

停滞日を除いた走行日のみで換算すると、**1日平均でおよそ87km**進行した計算になります。

---

## 出費の内訳

ユーラシア大陸横断にかかった総費用は **550,405円** です。

### 内訳

| 項目 | 金額 | 備考 |
| :--- | :--- | :--- |
| **移動費** | 179,423円 | 航空券・長距離移動費など |
| **宿泊費** | 66,526円 | 102泊分（野宿・キャンプ活用） |
| **ビザ関連** | 27,134円 | 各国ビザ取得費用 |
| **その他（装備・医療）** | 50,200円 | 自転車パーツ、ワクチン等 |
| **食費・雑費** | 227,121円 | 日常の食費・日用品など |
| **合計** | **550,405円** | |

生活費（食費・雑費）を全期間（364日）で割ると、**1日あたり約624円** となります。
